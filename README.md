# JavaScript-Programming

This repository contains two mini projects.

1. Registration Form with Validation
   
Description
A simple registration form that accepts Name, Email, and Password and validates the fields in real time.

Features
Validates that the Name field is not empty.
Checks that the Email contains @ and ..
Ensures the Password has at least 6 characters.
Displays error messages when the fields are invalid.
Enables the Submit button only when all fields are valid.
Displays a success alert when the form is submitted.

Technologies Used
HTML
CSS
JavaScript

--------------------------------------------------------------------------------

2. Character Counter
   
Description
A simple text area that counts characters as the user types and displays the remaining characters allowed.

Features
Allows the user to type a message.
Sets a maximum limit of 200 characters.
Updates the character count in real time.
Displays the number of characters typed, such as 150/200 characters.
Displays the number of remaining characters.
Shows an alert when the maximum character limit is reached.
Prevents the user from typing more than 200 characters.

Technologies Used
HTML
JavaScript


Add the character counter HTML and JavaScript code.
Open the file in a web browser.
Type a message and observe the counter and alert.
